# PlatformConfig Service

Der PlatformConfig Service stellt ein Micro-Frontend zur Plattformkonfiguration im Gaeco-Ökosystem bereit. Er ermöglicht die Konfiguration von Guidelines und Ontologien und wird als Modul in die Gaeco-Shell eingebunden.

## Enthaltene Dienste

- **PlatformConfig Client** (`platformconfig-client`) – Vue-Frontend, eingebunden unter dem Pfad `MOUNT_ROUTE`
